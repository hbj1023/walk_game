Walk Master 개인정보 처리방침

시행일: 2026년 8월 3일

Walk Master는 이동 기반 게임 기능을 제공하기 위해 필요한 최소한의 개인정보를 처리합니다.

1. 처리하는 정보

  • 이메일, 닉네임, 사용자 식별자와 사용자가 선택한 프로필 이미지
  • 레벨, 장비, 재화, 전투, 미션, 상점, 친구 및 레이드 기록
  • 걸음 수, 계산된 이동 거리와 부정 이용 방지 판정 결과
  • 고객센터에서 사용자가 입력한 발생 화면과 제보 내용
  • 오류 진단에 필요한 요청 시각과 서버 오류 기록

GPS 좌표는 이동 거리 확인과 부정 이용 방지를 위해 기기에서 처리합니다. 서버에는 원본 위도와 경도를 저장하지 않고 걸음 수, 계산된 거리와 판정 결과만 전송합니다.

2. 이용 목적

계정 관리, 걸음 기반 공격 기회와 보상 계산, 거리 기반 콘텐츠 운영, 게임 진행 저장, 친구·레이드 기능, 오프라인 공격 기회 알림과 고객 문의 처리에 사용합니다.

3. 권한 사용

  • 신체 활동: 걸음 수 측정과 오프라인 공격 기회 계산
  • 위치: 이동 거리 확인과 부정 이용 방지
  • 알림: 오프라인 공격 기회가 가득 찼을 때 안내
  • 인터넷: 계정과 게임 진행 정보 동기화

권한은 Android 설정에서 언제든 변경할 수 있으며, 거부하면 관련 기능이 제한될 수 있습니다.

4. 보관과 삭제

정보는 서비스를 제공하는 동안 보관합니다. 앱의 설정 > 고객센터 > 계정 삭제에서 즉시 삭제하거나, 앱을 사용할 수 없는 경우 웹 계정 삭제 요청을 제출할 수 있습니다. 삭제가 완료되면 계정과 연결된 게임 데이터가 삭제됩니다. 법적 의무 또는 보안상 필요한 기록은 해당 목적에 필요한 기간 동안만 별도로 보관할 수 있습니다.

5. 제3자 처리

개인정보를 판매하지 않습니다. 비밀번호 재설정 메일과 사용자가 선택한 외부 로그인 기능을 제공하는 데 필요한 범위에서 관련 서비스 제공자가 정보를 처리할 수 있습니다.

6. 보호 조치

앱과 서버 간 통신에 HTTPS를 사용하고, 운영 데이터 접근을 제한하며, 배포 전 백업과 복구 절차를 운영합니다.

7. 이용자 권리와 문의

개인정보 열람, 정정, 삭제와 기타 문의는 앱의 설정 > 고객센터에서 접수할 수 있습니다.

본 방침이 변경되면 이 페이지의 시행일과 내용을 갱신합니다.
