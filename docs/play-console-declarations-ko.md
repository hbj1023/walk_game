# Walk Master Play Console 제출 초안

이 문서는 Play Console에 입력할 내용을 현재 앱 구현 기준으로 정리한 초안이다. 스토어 제출 직전에 실제 SDK 동작과 운영 정책을 한 번 더 대조한다.

## 앱 기본 정보

- 앱 이름: Walk Master
- Android 패키지명: `com.hbj1023.walkmaster`
- 개인정보 처리방침: `https://walk-master.com/privacy.html`
- 외부 계정 삭제 요청: `https://walk-master.com/delete-account.html`
- 앱 카테고리: 게임
- 광고 포함: 현재 코드 기준 광고 SDK 없음

## Data safety 입력 초안

### 수집하는 데이터

| 구분 | 항목 | 필수 여부 | 용도 |
| --- | --- | --- | --- |
| 개인정보 | 이메일, 사용자 ID, 닉네임 | 필수 | 회원가입, 로그인, 계정 관리 |
| 개인정보 | 프로필 이미지 | 선택 | 게임 프로필 표시 |
| 앱 활동 | 게임 진행, 전투, 장비, 재화, 미션, 친구, 레이드 기록 | 필수 | 핵심 게임 기능과 동기화 |
| 건강 및 피트니스 | 걸음 수 | 필수 기능 | 공격 기회와 이동 콘텐츠 계산 |
| 위치에서 파생된 정보 | 계산된 이동 거리와 부정 이용 판정 | 관련 기능 사용 시 | 이동 검증과 부정 이용 방지 |
| 사용자 콘텐츠 | 고객센터 제보 내용 | 선택 | 문의와 오류 처리 |
| 앱 정보 및 성능 | 요청 시각과 서버 오류 기록 | 자동 | 안정성, 보안, 장애 진단 |

GPS 원본 위도·경도는 기기에서 거리 계산에 사용하고 서버에 저장하지 않는다. 원본 좌표를 서버나 제3자 SDK에 전달하는 구현이 추가되면 이 선언을 반드시 갱신한다.

### 처리 및 보호

- 판매: 하지 않음
- 전송 중 암호화: HTTPS 사용
- 계정 삭제: 앱 내부 즉시 삭제와 외부 웹 요청 모두 제공
- 데이터 공유: 메일 전송, 외부 로그인 등 기능 제공에 필요한 처리자가 있을 수 있으므로 Play Console의 최신 정의와 실제 SDK 정책을 확인 후 최종 선택

## 건강 앱 선언

- 관련 기능: 활동 및 피트니스
- 목적: 걸음 수를 게임 공격 기회와 이동 기반 보상으로 변환
- 의료 진단, 치료, 질병 관리 기능: 없음
- 건강 정보의 광고 활용 또는 판매: 없음

## Android 권한 설명

| 권한 | 사용자 설명 |
| --- | --- |
| `ACTIVITY_RECOGNITION` | 걸음 수를 측정해 공격 기회를 계산합니다. |
| `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION` | 실제 이동 거리를 확인하고 이동 수단 등을 이용한 부정 획득을 줄입니다. |
| `POST_NOTIFICATIONS` | 오프라인 공격 기회가 가득 찼을 때 알려 줍니다. |
| `INTERNET` | 계정과 게임 진행 정보를 서버와 동기화합니다. |

## 계정 삭제 운영 절차

1. 앱 내부 삭제는 비밀번호 재확인 뒤 계정과 연결 데이터를 즉시 삭제한다.
2. 웹 요청은 PocketBase `account_deletion_requests` 컬렉션에 `pending`으로 저장된다.
3. 운영자는 요청 이메일의 계정 소유 여부를 확인한다.
4. 본인 확인 후 계정과 연결 데이터를 삭제하고 상태를 `completed`로 바꾼다.
5. 확인이 불가능하거나 부정 요청이면 사유를 운영 기록에 남기고 `rejected`로 바꾼다.

웹 요청 양식에서는 비밀번호를 받지 않는다. 요청자에게 계정 존재 여부를 즉시 노출하지 않는다.

- 타깃 API, 콘텐츠 등급, 대상 연령, 광고 여부, 국가/지역 설정 확정
